# 数字で会社を読む

経営分析論Ⅱ(中間テスト範囲)を、縦書きの電子書籍として読むための個人用Webアプリ。

- 縦書き・右から左。画面の左側をタップ(または右へなぞる)で次のページ、真ん中のタップで目次や文字の大きさ
- 読んだ位置・章の状態(未読/読み途中/読了)・節の既読・章末のチェックは、iPhone と iPad の間で自動で同期(Supabase `shinsho_progress`)
- 一度開けばオフラインでも読める。オフライン中の記録は、つながったときに自動で送る
- 耳で聞ける:耳用に書き直した原稿(`chapters/ear/`)を端末の声で読み上げる。聞いた記録(聴)は読んだ記録(読)とは別に残し、聞いただけの節は目次で朱色になる。聞いている間は画面を点けたままにする

## iPhone・iPad への入れ方

1. 公開URLを **Safari** で開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はホーム画面のアイコンから開く(全画面で読める)

オフラインで読みたい端末では、出かける前に一度開いておくこと(そのとき端末に保存される)。
